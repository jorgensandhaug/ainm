## 4. Likely Root Cause

**Check 3 failed because the missing VAT correction used the "other branch" (expense + vatType=1) instead of direct 2710 posting.**

The original voucher (609013207 "Varekjøp uten MVA") had:
- 6500: net=19800, gross=24750, vatType=1
- 2710: amount=4950 (auto-generated by Tripletex from vatType=1)
- 2400: -24750, supplier=108369169

The agent detected the existing 2710 posting and used the "other branch":
- Posted `6500 +6187.5 gross, vatType=1` → auto-generated `2710 +1237.5` only
- Posted `2400 -6187.5`

While this produces correct final **balances** (6500 net=24750, 2710=6187.5, 2400=-30937.5), the **auto-generated 2710 posting amount is only 1237.5** — the scorer likely expected a direct 2710 posting of 6187.5 (or the shortfall 1237.5 posted directly, not auto-generated).

The correct approach: post the VAT shortfall directly on 2710 with vatType=0 or no vatType, and fix the expense net separately with vatType=0:
```
{ 2710: +1237.5 }                          // VAT shortfall
{ 6500: +4950, vatType: { id: 0 } }       // expense net shortfall
{ 2400: -6187.5, supplier: {...} }         // counterpart
```
