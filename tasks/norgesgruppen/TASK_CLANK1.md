This task is object detection and classification of grocery shelves. There are already YOLO models in the repo that have been finetuned for this. Your task is to train new models, make the training process better and make them more robust. The gold metric here is the score, given by detection mAP@50 (70%) and classification mAP@50 (30%). After new models are trained, you can use multiple models to make an ensemble, do test-augmentation to make them better, and other post-processing tricks. The baseline is already quite good, but your task is to squeeze out more performance at every step. However, keep in mind that the final solution must be less than 420 MB (including model weights), and run in 300 seconds on the test server, which has an L4 GPU. More information about this can be found in the AI NM docs. It is important that you do not leak data (for instance, ensure that all models train on the same train/val split). If you are able to improve the gold metric, copy and move all relevant files to a new folder. Remember to document everything and be thorough. It is important that new improvements are reproducible later if we wish to submit it to the test server. Our best attempt gets roughly 0.89 score, while the top performers get close to 0.93. Your goal is to close this gap through innovation, iteration and improvement.

In the docs there are strict rules regarding what libraries you can use, file sizes, and which imports you can do (e.g. import os is not allowed) regarding submission, so you need to follow this strcitly in your modelling aswell.
