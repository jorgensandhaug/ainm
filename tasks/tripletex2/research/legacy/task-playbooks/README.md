# Task Playbooks

These files are verbatim reference copies from `tasks/tripletex/codex-environment/task-playbooks/`.

In `tripletex2`, they are source material for coding agents implementing or revising deterministic task strategies. They are not runtime code.

Use these playbooks to:
- understand the broader expected flow for a task shape
- compare a candidate strategy against legacy task guidance
- identify when a task should stay flexible instead of being narrowed into a trusted standard

If a copied playbook conflicts with tested `tripletex2` strategy evidence, keep the playbook copy intact and resolve the difference in strategy code, strategy docs, or run evidence.
